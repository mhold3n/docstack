# docstack

Marketplace repo for [docstack](./plugins/docstack) — docs/PDF twin of pstack.

## Install in Cursor

1. Dashboard → Plugins & MCPs → Add Marketplace → Import from Repo
2. Paste `https://github.com/mhold3n/docstack`
3. Install the **docstack** plugin from that marketplace
4. Reload the window

Plugin sources live under `plugins/docstack/` (Cursor multi-plugin layout).
