### PDF review

**You own the review. Report findings unless asked to fix.**

1. Locate the PDF. Render every page (or the requested range) to PNG via the **document-pdf** skill / `pdftoppm`.
2. Inspect each page for layout and content defects. Check clipping, overlap, contrast, and alignment. Also check broken tables, missing images, bad headers or footers, pagination, and placeholder strings.
3. Spot-check claims against authority when the review includes accuracy, not layout alone.
4. Report findings by page number with severity (blocking / suggestion / nit). Do not edit unless the user asked for fixes. If they did, hand off to **PDF produce** or **Fact fix** with the finding list.

**Reply:** page-by-page findings, PNGs path, pass/fail recommendation.
