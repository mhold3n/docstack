# Architect

Before drafting, trace every corpus the change touches. Sketch two shapes for it: Diátaxis mode, heading taxonomy, nav placement, cross-links, and claim ownership. Pick the shape where each topic has one owner page, each reader task has one path, and callers need to know least. Redesign instead of patching if caveats and workarounds repeat.

For a large or contested design, run the **document-arena** skill instead of sketching alone.
