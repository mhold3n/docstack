### Investigation

**You own the answer. Plan, route, write.**

Investigation requests do not write. They produce a cited explanation or a recommendation. They do not change docs.

1. Trace the docs or corpus the question is about. For motivation questions, also route through the **why** skill.
2. Throughput checkpoint stays one line: `throughput checkpoint: n/a, investigation (no writes)`.
3. Produce the output (Overview / Key Concepts / How It Works / Where Pages Live / Gotchas), or a recommendation with a tradeoffs table if the request is a decision between alternatives.
4. Apply the **unslop** skill to the reply.

No PR, no babysit, no `architect` unless the investigation precedes a docs change. If it does, hand back to the user and re-route to Fact fix or Chapter.

**Reply:** the investigation output. For "are we sure?" answers, include your real judgment with reasons. Push back if the premise is wrong (see Autonomy).
